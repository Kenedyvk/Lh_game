# LH Games 🎮

Projeto acadêmico de Front-End para a atividade do SENAI: desenvolvimento de uma página inicial e uma página de login para uma loja de eletrônicos voltada ao universo gamer.

## Tecnologias
- HTML5 semântico
- CSS3 e media queries
- Bootstrap 5
- JavaScript
- jQuery

## Como executar
Abra o arquivo `index.html` no navegador. Bootstrap, jQuery e imagens são carregados por CDN, então é necessária conexão com a internet.

## Funcionalidades demonstrativas
- Carrossel de banners
- Cards de produtos e contador de carrinho
- Formulário de newsletter com validação
- Login demonstrativo com validação e opção de mostrar senha
- Formulário de cadastro demonstrativo
- Layout responsivo

> O login e o cadastro são demonstrações front-end. Não há autenticação real nem envio ou armazenamento de dados.
